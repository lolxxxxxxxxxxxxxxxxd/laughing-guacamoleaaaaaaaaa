Where a run happens

The site stores your workspace in this browser. Build & run sends the current project files, queued input, and arguments to Compiler Explorer at godbolt.org. Its API runs the program to completion with the queued input; it cannot accept live keystrokes after a run starts. Do not send secrets or private code.
